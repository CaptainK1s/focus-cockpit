# Focus Cockpit

A small, dependency-free browser app for running focused work sessions.

## Features

- Focus, short break, and long break timer modes
- Custom session length slider
- Task queue with local persistence
- Session, minute, and streak stats
- Dark neon cockpit interface
- Built-in ambient sound toggles, including a high-BPM rave pulse

## Run Locally

From this folder:

```sh
python3 -m http.server 4173
```

Then open:

```txt
http://localhost:4173
```

You can also serve it with any static file server.
